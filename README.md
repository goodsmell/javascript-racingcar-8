# 자동차 경주

## 구현 기능 목록

- 사용자는 자동차 이름을 콤마로 나열하여 입력한다.
- 잘못된 입력 시 게임을 종료한다.
- 사용자는 시도 횟수를 입력한다.
- 잘못된 입력 시 게임을 종료한다.
- 0~9 중 무작위 값이 4 이상이 나온 자동차만 전진한다.
- 시도 횟수 만큼 진행 후 가장 많이 이동한 자동차가 우승한다.

</br>

## 예외 처리 목록

| 예외 사항                             | 에러메시지 |
| ------------------------------------- | ---------- |
| 자동차 이름을 입력하지 않음           | [ERROR]    |
| 각 자동차 이름이 5자를 초과함         | [ERROR]    |
| 시도 횟수를 입력하지 않음             | [ERROR]    |
| 시도 횟수에 0을 입력함                | [ERROR]    |
| 시도 횟수를 숫자 이외의 문자를 입력함 | [ERROR]    |
| 너무 많은 수를 입력함                 | [ERROR]    |
