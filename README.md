# 자동차 경주

## ✨ 구현 기능 목록

| 번호 | 구분        | 주기능                 | 상세기능                                                                                                                                                                                      | 설명                                                              |
| ---- | ----------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 1    | 사용자 입력 | **1.1** 자동차 등록    | **1.1.1** 사용자는 자동차 이름을 `콤마(,)`로 구분하여 입력한다.</br> **1.1.2** 이름은 `1~5`자여야 하며, `중복`이나 `빈 이름`은 허용되지 않는다. </br> **1.1.3** `띄어쓰기`는 적용되지 않는다. | 잘못된 입력 시 `[ERROR]` 메시지를 출력하고 프로그램을 `종료`한다. |
|      |             | **1.2** 시도 횟수 입력 | **1.2.1** 사용자는 `경주를 시도할 횟수`를 입력한다. </br>**1.2.2** 시도 횟수는 `자연수(1 이상의 정수)`만 허용한다.                                                                            | 잘못된 입력 시 `[ERROR]` 메시지를 출력하고 프로그램을 `종료`한다. |
| 2    | 경주 진행   | **2.1** 라운드 진행    | **2.1.1** 각 라운드 마다 `0~9 사이의 무작위` 값을 생성한다 </br> **2.1.2** 무작위 값이 `4이상`이 나온 자동차는 `1칸 전진`한다.                                                                | 라운드가 끝날 때 마다 각 자동차의 이동 상태를 출력한다            |
| 3    | 결과 출력   | **3.1** 우승자 판정    | **3.1.1**시도 횟수 만큼 경주 진행 후 `가장 많이 이동한 자동차`를 우승자로 판정한다 </br> **3.1.2** 이동거리가 같은 자동차가 여러 대일 경우 `공동 우승자`로 처리한다.                          | `최종우승자 : a,b` 형식으로 출력                                  |

</br>

##  🚨  예외 처리 목록

| 예외 사항                              | 에러메시지                                                          |
| ------------------------------------------ | ------------------------------------------------------------------- |
| 자동차 이름을 아예 입력하지 않음           | [ERROR] 자동차 이름이 입력되지 않았습니다. 한 개 이상 입력해주세요. |
| 중복된 자동차 이름 입력                    | [ERROR] 중복된 자동차가 등록되었습니다.                             |
| 빈 이름을 입력함 ex) a,,b                  | [ERROR] 빈 이름이 존재합니다.                                       |
| 각 자동차 이름이 5자를 초과함 ex)abcde,abc | [ERROR] 자동차 이름이 5자를 초과하였습니다.                         |
| 너무 많은 자동차가 입력됨                  | [ERROR] 너무 많은 자동차가 입력되었습니다.                          |
| 시도 횟수를 입력하지 않음                  | [ERROR] 시도 횟수가 입력되지 않았습니다.                            |
| 시도 횟수에 0 이하를 입력함                | [ERROR] 시도 횟수는 1 이상이어야 합니다.                            |
| 시도 횟수를 숫자 이외의 문자를 입력함      | [ERROR] 시도 횟수는 숫자를 입력해 주세요                            |
| 너무 큰 시도횟수를 입력함                  | [ERROR] 너무 많은 시도는 할 수 없습니다.                            |
